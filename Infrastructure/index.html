How elplayerlab.com works

From the final buzzer to your phone, with no one in the loop.

Every game night a robot in GitHub Actions reads the official Euroleague feeds, checks them, runs its models over them and publishes a new site. If anything looks wrong, nothing goes live and yesterday’s site stays up.

~10 minfrom a game going final to the new pages
4 gatesevery build passes before it is published
174,553shots from four seasons teach the xFG model
$0a month: free tiers of GitHub, Render and GoatCounter

Game night

An outside scheduler pings GitHub every five minutes on game evenings, because GitHub’s own timer often fires late. A run only starts when a game has gone final; the 02:30 UTC run always goes, to pick up roster changes and late score corrections.

Code changes

Changes to the site itself take a separate route. Nothing deploys from a pull request; the site only updates after the same checks pass again on main.

The models behind the numbers

Five pieces of modelling sit between the raw feed and the page. Two of them feed others: xFG gives every shot an expected value, and the lineup rebuild gives RAPM its stints.

How the xFG model is looked after

The shot model is treated like a small production system: each version is trained on a branch, recorded with fingerprints of its data, served through an API, and watched round by round.

How good the models are

Each model is tested on games it never saw. Lower log loss is better.

What it runs on

DataPython 3.11, DuckDB SQL over Parquet tables, pandas
Modelsscikit-learn (gradient boosting, logistic regression), NumPy; model files kept in the repo
SiteOne HTML file built from template.html, per-club and per-game JSON, Turkish strings in lang/tr.json, offline cache via a service worker
AutomationGitHub Actions: update, test, pages, retrain, service; Dependabot every Monday
QualityPython self-tests, 30 SQL assertions, drift check, ESLint, TypeScript checker, Playwright and headless Chrome
HostingGitHub Pages for the site, Render free tier for the xFG API, GitHub Container Registry for its image
AnalyticsGoatCounter page counts and error reports, no cookies
